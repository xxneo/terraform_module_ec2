
# Terraform Module for AWS EC2 Creation

⚡ About the Module:

⭐ The AWS region for the module is North Virginia (us-east-1)

⭐ Create an EC2 with the below details:

        👉 Instance Type is t3.micro (free tier)
        👉 OS is Windows latest as of October 2025.

⭐ Names the EC2 Instance created as Custom_Module_EC2 using tags.

⭐ Creates a Tag on the EC2 created with creation date using the formatdata() and timestamp() function.

⚡ Module Block example is stored in "module_example.tf"
